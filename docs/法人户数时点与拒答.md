# 法人户数：库内最新批次与用户提问时点

## 最新批次判定

- 数据源：`dws_cqs_enterprise_query_view_full`，条件 `is_exit_press_reduce = '是'`。
- **以 `MAX(version_code)`（YYYYMM）为准**；若不可用再回退 `MAX(create_date)`。

## 用户明确问到「未来月份」时：拒答（不静默改 SQL）

当同时满足：

1. 问题属法人户数意图（含「法人户数」，或「户数」且含「集团/法人」）；
2. 问句中能解析出 **「YYYY年M月」**（正则：`(\d{4})\s*年\s*(\d{1,2})\s*月`）；
3. 该 **YYYYMM 大于** 库内上述 `MAX(version_code)` 对应批次；

则 **不调用大模型生成 SQL、不执行查询**，直接返回提示：

- 说明库内数据最新仅到 **YYYY年MM月**；
- 请用户将提问时间改为该月及以前。

### 触发位置

1. **主流程**（`llm.py`）：SQL 生成步骤开始后、快速模板匹配之前。
2. **`generate_sql()`**：与表选择 `no_data` 并列，防止仅走常规模型路径时漏拦。

## 未带明确「年+月」时

- 模型仍可能生成未来 `version_code`：**`check_save_sql` 内 `_cap_cqs_sql_snapshot_time`** 会将 SQL 中的批次回写为库内最新（兜底）。
- 若用户只写「4月」未写年份，当前 **不会** 走拒答（需后续结合上一轮时间再增强）。
